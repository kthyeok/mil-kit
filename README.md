# Mil-Kit 🍳 — 당신의 군생활을 요리해 드립니다

병사의 진급 과정(이병 → 일병 → 상병 → 병장)을 게임처럼 따라가며 모은 답으로
**채용공고 조건**과 **국가자격(Q-Net) 필터**를 만들고, 필요한 자격증 코스와 맞춤 공고를 보여주는 모바일 웹 데모입니다.

## 바로 열어보기
- GitHub Pages: https://kthyeok.github.io/mil-kit/
- (Pages 설정 전 임시 미리보기) https://htmlpreview.github.io/?https://github.com/kthyeok/mil-kit/blob/main/index.html

## 구성
- `index.html` 한 파일로 동작합니다. 외부 라이브러리·폰트·네트워크 요청이 없습니다.
- 군 선택: 육군 · 해군 · 공군 · 해병 · 기타(상근예비역 · 카투사 등)
- 흐름: 스플래시 → 입대 → 병무청 신상명세서(학력·전공) → 자대 배치 면담 → 계급별 생활 이벤트 → 요리(결과)
- 결과: 오늘의 메뉴 · 코스 서비스(자격 로드맵) · 채용공고 · 자격증 · 전역카드/명함 · 선후임 공유(도전장 링크)

## 데이터 안내 (DEMO)
- 채용공고·자격 정보는 API 명세의 필드 구조만 참고해 만든 **목업**입니다.
- 실제 연동 시 API 키(채용정보 계정, 공공데이터포털 serviceKey)는 백엔드 프록시에만 둡니다.
- 입력한 학력·전공·이름 등은 브라우저 안에서만 쓰이며 어디에도 전송되지 않습니다.
